about=IsoParcel partitions input polygon layers into equal-area parcels using an adaptive orthogonal cutting algorithm with binary search convergence. Invalid geometries are repaired before cutting. For multipart features only the largest part is subdivided, and a warning is shown. Successful subdivisions reach an area coefficient of variation below 0.01%%; features that produce fewer parcels than requested are reported in the log. Suited to cadastral, agricultural and experimental design workflows. Integrated into the QGIS Processing Toolbox for batch and model workflows. Concept initiated 2026-05-15.
